## اولویت فعلی

> Core Physics First. Everything Else Second.

یک Standard Marble داخل یک Arena، با Mouse Aim و Power، برخورد با چند Marble دیگر — آن‌قدر خوب که بدون هیچ Feature دیگری سرگرم‌کننده باشد.
