# Project Marbles — Roguelike Redesign v0.4

**وضعیت:** Design → Implementation
**جایگزین می‌کند:** ساختار Campaign ده‌مرحله‌ای در SPEC v0.3 §64
**دست نمی‌زند به:** فیزیک، قابلیت تیله‌ها، AI، Juice — همه سر جایشان می‌مانند

---

## 1. چرا این تغییر

Campaign ده مرحله‌ی ثابت بود: می‌بردی، می‌رفتی جلو، تمام. Balatro ساختار دیگری دارد و چیزی که آن را اعتیادآور می‌کند **Campaign** نیست، این است:

1. هر Run از صفر شروع می‌شود و **باختن یعنی از اول**
2. هدف امتیازی **نمایی** بالا می‌رود، پس بازیکن مجبور است Build بسازد نه فقط خوب بازی کند
3. بین مراحل **Shop** هست که Buildها از آنجا می‌آیند
4. امتیاز `Chips × Mult` است — دو عدد که جدا رشد می‌کنند و حاصل‌ضربشان منفجر می‌شود
5. **Boss** هر بار یک قانون را می‌شکند
6. هر Run متفاوت است

همین‌ها به تیله‌بازی منتقل می‌شوند. Gameplay دست نمی‌خورد — همان Select → Place → Aim → Power → Flick.

---

## 2. ساختار Run

```text
RUN
 └── Ante 1..8                        (هر Run هشت Ante)
      ├── Small Table    هدف امتیاز پایه
      ├── Big Table      1.5× هدف
      └── Boss Table     2× هدف + یک قانون شکسته
           └── Shop بعد از هر Table
```

**Table** همان چیزی است که Balatro به آن Blind می‌گوید. هر Table:

- یک **Score Target**
- تعداد مشخصی **Shot** (پیش‌فرض ۵)
- یک **Arena** که از Poolی از چیدمان‌ها انتخاب می‌شود

اگر در Shotهای موجود به Target نرسیدی: **Run تمام است.**

---

## 3. امتیاز — Chips × Mult

این قلب تغییر است. امتیاز دیگر جمع ساده نیست:

```text
Round Score = Chips × Mult
```

| | از کجا می‌آید |
|---|---|
| **Chips** | ارزش پایه‌ی هر Target که بیرون می‌رود یا داخل چاله می‌افتد |
| **Mult** | طول زنجیره، نوع تیله، Charmها |

مثال یک شات:

```text
سه Target بیرون رفت       Chips 30
زنجیره‌ی سه‌تایی            Mult  3
Charm «Chain Gang»        Mult  +2
                          ────────────
                          30 × 5 = 150
```

دو عدد کوچک که جدا رشد می‌کنند و حاصل‌ضربشان بزرگ می‌شود — دقیقاً همان مکانیزمی که در Balatro باعث می‌شود Build مهم‌تر از مهارت لحظه‌ای شود.

### اعداد پایه

| Event | Chips | Mult |
|---|---:|---:|
| Target از حلقه بیرون | +10 | — |
| Target داخل چاله | +12 | — |
| هر حلقه‌ی زنجیره بعد از اولی | — | +1 |
| Bank Shot | +5 | — |
| تیله‌ی خودت بیرون رفت | −8 | — |

Mult پایه‌ی هر شات: `1`

## 4. Score Target

```text
Target(ante, table) = BASE × GROWTH^(ante-1) × TABLE_MULT
```

```text
BASE   = 60
GROWTH = 1.75
TABLE_MULT:  Small 1.0   Big 1.5   Boss 2.0
```

| Ante | Small | Big | Boss |
|---:|---:|---:|---:|
| 1 | 60 | 90 | 120 |
| 2 | 105 | 158 | 210 |
| 3 | 184 | 276 | 368 |
| 4 | 322 | 482 | 643 |
| 5 | 563 | 844 | 1,125 |
| 6 | 985 | 1,477 | 1,970 |
| 7 | 1,723 | 2,585 | 3,447 |
| 8 | 3,016 | 4,524 | 6,032 |

بدون Build، یک شات خوب حدود `30 × 3 = 90` می‌دهد. یعنی تا Ante 3 با مهارت می‌شود جلو رفت و از آنجا به بعد **اجباراً** باید Build ساخت. همان شکل منحنی Balatro.

> این اعداد حدسی‌اند و بعد از Playtest باید تنظیم شوند. `GROWTH` تنها عددی است که کل سختی Run را می‌چرخاند.

## 5. اقتصاد

| | |
|---|---|
| بردن یک Table | `$4` Small · `$5` Big · `$7` Boss |
| هر Shot استفاده‌نشده | `$1` |
| بهره | `$1` به ازای هر `$5` موجودی، سقف `$5` |

بهره همان کاری را می‌کند که در Balatro: وسوسه‌ی پس‌انداز در برابر خریدن حالا.

## 6. Charms — معادل Joker

**Charm** یک شیء دائمی است که تا آخر Run با شماست و قوانین امتیاز را عوض می‌کند. حداکثر **۵ تا** هم‌زمان.

این مهم‌ترین بخش طراحی است، چون Build از اینجا می‌آید. قواعد:

- هر Charm با یک جمله قابل توضیح باشد
- Charm هیچ Input جدیدی نمی‌سازد
- Charmها باید با هم **ترکیب** شوند، نه فقط جمع
- هیچ Charmی نباید در هر Buildی بهترین باشد

### دسته‌بندی

| دسته | کار |
|---|---|
| **Chips** | عدد پایه را بالا می‌برد — مطمئن ولی خطی |
| **Mult** | ضریب را بالا می‌برد — کم‌اثر به‌تنهایی، منفجر با Chips |
| **Conditional** | شرط دارد. بیشترین قدرت، کمترین اطمینان |
| **Economy** | پول. ضعیف در لحظه، قوی در طول Run |
| **Physics** | قوانین فیزیک را عوض می‌کند — چیزی که هیچ بازی کارتی نمی‌تواند داشته باشد |

### ست اولیه

| Charm | دسته | اثر |
|---|---|---|
| **Weighted Core** | Chips | هر Ring Out `+6` Chips |
| **Chain Gang** | Mult | هر زنجیره `+2` Mult |
| **Clean Break** | Conditional | اگر هیچ تیله‌ای از دست ندادی `×2` Mult |
| **Last Call** | Conditional | آخرین Shot یک Table `×3` Mult |
| **Ricochet Plate** | Conditional | Bank Shot `+4` Mult |
| **Ballast** | Conditional | Heavy که Ring Out کند `+15` Chips |
| **Scalpel** | Conditional | Precision که Ring Out کند `+5` Mult |
| **Lodestone** | Physics | شعاع Pulse مغناطیس `+60%` |
| **Greased Rim** | Physics | حلقه `12%` کوچک‌تر |
| **Dead Weight** | Physics | Targetها `30%` سبک‌تر |
| **Collector** | Economy | هر Ring Out `$1` |
| **Usurer** | Economy | سقف بهره `$5 → $10` |
| **Patient** | Economy | هر Shot استفاده‌نشده `$2` به جای `$1` |
| **Overdraw** | Utility | یک Shot اضافه در هر Table |
| **Deep Pockets** | Utility | یک Slot اضافه برای Charm |

ترکیب‌های موردنظر: `Chain Gang + Dead Weight` (زنجیره آسان‌تر)، `Ballast + Weighted Core` (Chips سنگین)، `Greased Rim + Last Call` (خطرناک ولی انفجاری).

## 7. Boss Tables

هر Boss یک قانون را می‌شکند. در هر Ante یکی تصادفی انتخاب می‌شود.

| Boss | قانون شکسته |
|---|---|
| **The Void** | حلقه `25%` بزرگ‌تر |
| **The Anchor** | Targetها دو برابر جرم دارند |
| **The Slick** | میز بدون اصطکاک — همه‌چیز سر می‌خورد |
| **The Blind** | Aim Guide خاموش |
| **The Miser** | این Table پولی نمی‌دهد |
| **The Duelist** | یک AI سر همان Targetها با تو رقابت می‌کند |
| **The Tithe** | هر Shot `$1` هزینه دارد |
| **The Cage** | فقط ۳ Shot |

**The Duelist** جایی است که کل کار AI زنده می‌ماند: به جای اینکه حریف همیشه باشد، تبدیل می‌شود به یک Boss که گاهی می‌آید — و چون نادر است، ترسناک‌تر هم هست.

---

## 8. Shop

بعد از هر Table. موجودی:

```text
۲ Charm        قیمت $4–$8
۱ Marble       تیله‌ی جدید برای Bag، $3–$6
۱ Polish       یک نوع تیله را دائمی ارتقا می‌دهد، $4
Reroll         $2، هر بار +$1
```

**Polish** معادل ارتقای کارت در Balatro است: مثلاً «Heavy از این به بعد `+3` Chips بیشتر می‌دهد» — روی همه‌ی Heavyهای Bag تا آخر Run.

---

## 9. Bag در طول Run

شروع: **۸ تیله، همه Standard**

Bag در Shop رشد می‌کند. برخلاف Campaign، محدودیت «هر Special فقط یکی» برداشته می‌شود — Bag با پنج Heavy یک Build معتبر است، و این دقیقاً همان جایی است که Balatro اجازه می‌دهد بازیکن افراط کند.

سقف Bag: **۱۲**

## 10. آنچه از v0.3 می‌ماند

همه‌ی کار قبلی دست‌نخورده باقی می‌ماند و زیر این ساختار استفاده می‌شود:

- فیزیک کالیبره‌شده و تست‌هایش
- شش تیله با قابلیت‌هایشان
- Shot Simulator و AI (حالا به‌عنوان Boss)
- کل لایه‌ی Juice: Cascade، Multiplier، Shockwave، Slow Motion
- Settings و Accessibility
- چیدمان‌های ده مرحله، که حالا Pool آرناها می‌شوند

---

## 11. آنچه حذف می‌شود

- Level Select خطی و قفل مرحله‌ای
- Medal و Secondary Objective (جایشان را Score Target می‌گیرد)
- Marble Trial به‌عنوان راه Unlock — تیله‌ها در Shop خریده می‌شوند
- Objective‌های نوع «Ring Out 3» — همه‌چیز Score Target است

Save تغییر می‌کند: به‌جای «کدام مرحله تمام شده»، **Run جاری** و **Metaی بین Runها** ذخیره می‌شود.

---

## 12. Meta بین Runها

کم و عمداً ساده:

- کدام Charmها تا حالا دیده شده‌اند (Collection)
- بهترین Ante رسیده
- تعداد Run برده/باخته
- Unlock شدن Charmهای جدید در Pool با رسیدن به Anteهای بالاتر

بدون ارتقای دائمی قدرت. Runها باید با مهارت و Build برده شوند، نه با Grind — همان قاعده‌ی §24 سند اصلی.
